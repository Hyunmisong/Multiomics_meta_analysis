# Integration

Combines the proteomics and phosphoproteomics results with genomics and scRNA-seq data.

```
genomics/     processing of the collaborator's variant / CNV data
scrna/        scRNA-seq processing and cell-type signatures
multiomics/   joint analysis across layers
```

Inputs come from `results/` of the other two parts plus the external data described in
`data/README.md`.
