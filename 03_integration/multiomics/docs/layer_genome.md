## What to keep in mind

- Truncating loss of function only -- no copy number, no missense, no structural variants. An absent signal means 'not recurrently truncated', never 'not altered'.
- One direction only: a truncation is loss, so this layer can never support an up-regulation.
- GG2 (n=25) produces no enriched pathway under any scheme, so the gastric side is effectively one cohort.
- Scored by its own schemes (g_*), because it has no effect size.
