## Caveat that bounds every number above

Tumour type is completely confounded with study: the four gastric proteome cohorts are four different studies, and so are the four oesophageal ones. Nothing in this design separates *gastric vs oesophageal* from *these four laboratories vs those four*. Sequencing depth is **not** confounded -- the measured-gene range overlaps between the types (gastric 3,903-11,340, oesophageal 1,714-9,325) -- but batch is. The split is justified on reproducibility grounds; calling it biology needs cohorts of both types from the same pipeline.
