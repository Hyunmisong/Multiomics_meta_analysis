## What to keep in mind

- Pseudobulk DESeq2 only: cells are summed per patient per lineage and tested across patients, so the unit of replication is the patient. Per-cell Seurat tests were not used.
- One vote per study. The same tumour-vs-normal contrast is run inside each cell lineage, so counting lineages would let a study win on annotation depth; the lineage that carried the call is kept as metadata instead.
- SG6 is excluded: its minimum padj is 0.168 across 180k rows.
- Six gastric studies against one oesophageal, so the tumour-type split cannot be asked of this layer.
